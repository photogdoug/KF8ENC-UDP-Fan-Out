## WSJT-X UDP Fanout GUI v2.3.0

This release simplifies the traffic display and improves application branding and destination entry.

### What’s new

- Replace per-application traffic plots with one blue line showing total packet traffic in both directions.
- Brand the main window as `WSJT-X UDP Fanout by KF8ENC`.
- Replace the destination-port spinner with a keyboard-friendly numeric field.
- Validate entered destination ports from 1 through 65535 before saving.
