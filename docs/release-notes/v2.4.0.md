## WSJT-X UDP Fanout GUI v2.4.0

This release uses WSJT-X's standard UDP configuration by default.

### What’s new

- Listen for WSJT-X UDP traffic on its default port, `2237`.
- Avoid requiring a port change in a standard WSJT-X installation.
- Keep JTSync on `2238`, move GridTracker to `2239`, and move WRL CAT Control to `2240` so no destination conflicts with the relay listener.
- Default newly added custom destinations to port `2241`.

Existing user configuration files remain unchanged during upgrades.
