## WSJT-X UDP Fanout GUI v2.2.0

This release adds full application theme customization to the Windows GUI.

### What’s new

- Choose from Light (default), Dark, Papirus, Nord, and Dracula themes.
- Apply theme changes immediately without restarting the relay.
- Remember the selected theme between application launches.
- Theme the dashboard, destination table, controls, editor dialog, and traffic chart consistently.
- View screenshots of every available theme in the repository README.

### Installer

Download `WsjtxUdpFanout-Windows-GUI-v2.2.0-Setup.exe` below. It is a self-contained 64-bit Windows installer and does not require a separate .NET installation.

SHA-256: `53368472FB39D976CFEE3C693AEDB34A9441F20ECE0DFDF56DE4CA7B28BE360C`
