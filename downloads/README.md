# Installer Options

## Windows GUI v2.4.0 — Recommended

[`WsjtxUdpFanout-Windows-GUI-v2.4.0-Setup.exe`](WsjtxUdpFanout-Windows-GUI-v2.4.0-Setup.exe)

The current Windows desktop application. It listens on WSJT-X's default UDP port 2237 and provides Start/Stop controls, destination editing, aggregate traffic statistics, a single total-packet traffic graph, WSJT-X source status, recent activity, and five selectable color themes without opening a command-prompt window.

SHA-256: `7F688464E4A49FA67191FF518FC4506D8628C4C5ACD82FBCF4ECC607EACC2D28`

## Console v1.3 — Classic

[`WsjtxUdpFanout-Console-v1.3.0-Setup.exe`](WsjtxUdpFanout-Console-v1.3.0-Setup.exe)

The original command-prompt dashboard. Choose this version if you prefer typed management commands or want to preserve the earlier interface.

SHA-256: `690D2B72868456BF5F5A53991F48759AB4F49DDB11539675BC487A4BACDDAF37`

Both installers contain self-contained 64-bit Windows applications and do not require a separate .NET installation. Neither installer is currently Authenticode-signed, so Windows may display an unknown-publisher warning.
